
INSTRUCCIONES DE USO:

1. Tener VSC INSTALADO junto con PYTHON

2. ABRE el archivo "WORKSHOP-P1G7.py" en VSC

3.Abre la terminal integrada en VS Code (Ctrl + ~ o Terminal > New Terminal) y ejecuta el siguiente comando: "pip install matplotlib numpy pandas seaborn"
para instalar las librerias pertinentes

4. ejecuta el codigo, se abre una ventana con 6 pestañas, cada una nombrada en relacion
a las TASK que cumple. 

5. hacer clic en la pestaña que desee visualizar.

6. listo!

NOTA: cada vez que se vuelve a ejecutar el codigo, el data generator vuelve a generar
un data set con valores diferentes
